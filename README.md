# Лабораторна робота № 3. Функції в Python

**Варіант 5.**

## Мета

Навчитися створювати функції користувача з параметрами та `return`, а також використовувати lambda-функції.

## Завдання

1. Функція обчислює вартість передавання даних залежно від обсягу та ціни за 1 МБ. Якщо обсяг перевищує ліміт, застосовується інший тариф. Вартість обчислюється для кількох обсягів із діапазону.
2. Lambda-функція переводить мегабайти в кілобайти.

## Теорія

* Функція створюється через `def`, отримує дані параметрами і повертає результат через `return`.
* Lambda — коротка анонімна функція: `lambda mb: mb * 1024` (1 МБ = 1024 КБ).
* Умова ЛР рекомендує діапазон 10..100 із кроком 10 — він заданий у програмі: `range(10, 101, 10)`.
* Припущення: якщо обсяг **більший** за ліміт, увесь обсяг рахується за ціною «понад ліміт»; якщо рівний ліміту — за звичайною ціною.

## Запуск

Потрібен Python 3.10+ (перевірка: `python --version`). Сторонні бібліотеки не потрібні.

```bash
python main.py
```
